## Описание

Приложение для мониторинга обработки данных в технологических процессах с рендерингом дашбордов и отправкой уведомлений.

## Технологии

Python, Dash

## Особенности

- Цетрализованное хранение метрик
- Дашборды
- Рассылка уведомлений и отчётов
